# 软件结果整体分析（2026-10-20）

依据：经过审查的结果文档，包括 results/analysis/causal_main_20261019（两轮审查）、stream_f7_20261019（三轮）、p0solve_20261019、drift_curve_20261016、expansion_20261016/round1、m2_calib_20261016、semg_calib_20261016、baselines_20261016、hybrid_identity_v2_20261017。

## 一、按漂移场景
- 小漂移（days，2 个 target）：只有 P0 起作用。因果协议下 P0 为 0.679–0.743；W_α 和组合方法在 B ≥ 4 时低于 P0（B=16：0.669 对 0.734）；ridge-CCA 到 B=33 才追上（0.734）。
- 中到大漂移（sub-M 的 12 个漂移 target，sub-C month）：小 B 靠 P0，大 B 靠有监督的闭式对齐，S1 在此之上再加分。漂移 target 上 B=33 时，P0 0.215 → 组合方法 0.471（协议 a）/ 0.465（协议 b），ridge-CCA 0.409。sub-C 上，sc_0629 的 CCA+S1 比 ridge-CCA 高 +0.08 至 +0.10（6/6 个 target 为正）；sc_0708 不稳定。
- 通道固定（M2）：prior 已经很强；P0 约 +0.03（不显著）；低秩 readout ridge 在 B=33 时 +0.046。
- sEMG（每次重新贴电极）：闭式 ridge 很强，固定权重 calibrator 不占优，作为边界场景。

## 二、各方法的角色
- P0：小 B 时不可替代。B=1 时在 days、month、year 三层分别为 0.68 / 0.47 / 0.20，ridge-CCA 为负。两只动物上都远超 prior。弱点是优势随间隔缩小，并且对电极覆盖率和 session 质量敏感。
- ridge-CCA、W_α：大 B 时最强的闭式方法，B ≤ 2 时不可用；W_α 的效果取决于 α 的选择。
- S1-causal：叠加在 P0 上时稳定（从 B=8 起 0/12 个 target 为负），保住约 82% 的 R2 增益；叠加在 CCA 上时不稳定（20150512 在 B=4/8 时为 −0.21 / −0.18；sc_0708 在 B=4 时为 −0.12）。
- 组合方法：B=33 时最好，比 ridge-CCA 高约 +0.06（12/12 个 target 为正）；B=8/16 在严格协议下与 ridge-CCA 打平；days 层退化。

## 三、薄弱环节
1. 选参数据太少：每个 trunk 只有 1 个因果的选参 session（这是 days 层退化、保守门槛全部回退、B=8/16 结论脆弱的共同根源）。
2. 统计基础薄：12 个漂移 target 共用 1 个 backbone；sub-C 只有 2 个 backbone；days 层只有 2 个 target。
3. 单个 target 上的失败（CCA+S1）。
4. S1 评测时用零 state 单独前向，和实际推理不一致，属于软件层面的自洽性问题。

## 四、论文结论
- 已经可以写：P0 在少标签时的优势；大 B 时组合方法比 ridge-CCA 高约 +0.06（两种协议）；S1 叠加在 P0 上时稳定、不重放；忠实复现的已发表方法在小 B 时都不如 P0；提交延迟的影响不超过 0.005。
- 还需要补证据：B=8/16 的优势、days 层的退化、sub-C 上精修的稳定性。这些都需要更多选参 session，第 2 轮 Colab 可以提供。
