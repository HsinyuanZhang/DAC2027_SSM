# Stage 2': Track A and Track E on DANDI 000688 subject M

Date: 2026-10-05. Status: running at the time of writing; numbers are appended as runs land.

## 1. Protocol

1. Source pool: the six SPINT-protocol 2015 train sessions (0511, 0512, 0610, 0611, 0612, 0615; 15 to 30 M1 units per session).  Final sessions stay untouched.
2. Targets: the two dev sessions (0616, 0617; 17 units each).  This is the short-gap stratum.  The month-gap and year-gap strata are the next round.
3. One pretraining per family, shared by both targets (revision item 16).  The budget-extension rule retrains at double steps when the best step lands in the last 20 percent.
4. Bottleneck K = 12.  The FA initialisation and the target-side FA need K below the smallest unit count (15 in the pool, 17 on targets).  The M2 K sweep chose 32; on 000688 the unit count is the binding constraint.
5. Budgets 0, 2, 4, 8, 16, 33 labeled trials.  Query labels enter nothing.

## 2. What Was Built

1. `ssm_decode/set_attention.py`: E1 static-key set read-in that folds into the same K x N table the AP backbone consumes; per-unit descriptors (behavior-lagged association profile plus activity statistics); label-free descriptor convention (profile block zeroed after normalization) unified between training and evaluation.
2. `ssm_decode/set_pretraining.py`: episodic pretraining (C8.4).  Each step computes descriptors from a random trial subset, folds the table, and decodes other trials.  Unit subsampling, channel gain jitter, descriptor noise, and profile-block dropout run every step.
3. `ssm_decode/set_attention_eval.py`: budget-dependent evaluation with `e1_profile`, `e1_rate` (works at zero labels), `e2_ema` (causal re-folding), `e4_window` (activity-augmented descriptor per segment, the dynamic-key ceiling), plus set-property checks: unit-order permutation, unit-dropout curves at 10, 30, 50 percent.
4. Track A additions: `prior_correct` (revision 4.2.1) fits a closed-form per-channel ridge correction on a profile-prior table through the head path; `track_a_experiment` gained the `dandi688sm` task with variable unit counts.

Tests: fold permutation equivariance, descriptor layout and label-free fallback, prior-correction gain recovery (max relative error below 1 percent on synthetic data), gradient flow.  25 passed.

Two trainer defects were caught by smoke runs before any result was produced: unit-drop removed descriptor rows but only zeroed input columns, and the episode endpoint cap used the channel axis length instead of the time axis.  Both are fixed with the smoke evidence in the run logs.

### Track E rebuild v2 (review step 3, same day)

Implemented per review 4.1: learned activity encoder over handcrafted
per-unit statistics (E0-style, 8 statistics through a 16-wide encoder),

Next levers, in order: T4-style cosine-tuning descriptors (the CO task
carries target directions), a wider learned activity path, and a longer
schedule.  The warm-start-plus-distillation machinery itself is done and
reusable.

## 5. Decision Gates

**Verdict after the 2026-10-06 review: both gates are UNDETERMINED, not failed.**

- 4.2.5: the Track A numbers above come from an AP backbone that never
  retrained under the extension rule (the loop reused the first attempt's
  manifest; best_step equals the 2000-step budget and the run is
  bit-identical to the unconverged 10-04 training), and K = 12 exceeds the
  FA Ledermann identifiability limit (K <= 10 at 15 units), which explains
  the non-monotonic label curves and the target instability.  Both defects
  are fixed; the gate is re-judged after the compliant rerun.
- 4.7.6: all Track E target numbers in section 4 are INVALID: predictions
  were compared in normalized units against raw-unit behavior (A1), the set
  backbone never fit the source data (source R2 0.110 versus AP 0.611,
  review A2), and the permutation "check" was a tautology (A6).  The E4
  "ceiling adds nothing" claim is WITHDRAWN (A5: that variant was a segment
  re-fold with state resets and forward-looking windows, not a dynamic key).

Partial reading that survives: ui_grad is strong (0.639 at 33 trials on the
dev split).  But APST reaches 0.808 on the same six-session sub-M protocol
(final split, no target gradient), so the zero-gradient ceiling is far
above the current implementation, and the deficit is in the recipe, not
the concept.  Corrective plan: review section 4.1 (T4 descriptors, learned
activity encoder, trunk warm start from the converged AP backbone or
distilled source tables, source-fit gate before any target evaluation).

### Closing the E1b source gap (2026-10-07): done, and it exposed a gate miscalibration

Recipe changes, each validated against the descriptor-capacity
diagnostics:

1. MLP read-in consumes the raw standardized statistics directly (the
   diagnostic structure), bypassing the extra activity encoder.
2. Distillation regresses full-train-trial descriptors (pooled
   cross-session batches of 4096 unit-rows, profile-block dropout and
   light noise) onto the AP tables -- replacing episode-subset
   distillation.
3. Dual validation: ``source_val`` (all-train-trial descriptors,
   like-for-like with how the AP tables were fit) and ``episode_val``
   (33-trial descriptors, deployment scale).  Checkpoint selection and
   the gate read ``source_val``; both are logged.

Results:

| model | source_val | gate 0.6647 | episode_val | dev-target e1_rate |
|---|---:|---|---:|---:|
| v2 (episode distill + episodic) | 0.605 | fail | ~0.60 | 0.673 |
| **v3 distill-only (best step 0)** | **0.706-0.713** | **pass** | 0.01-0.04 | 0.333 |
| v3 + 8000 episodic steps | 0.558 (falling) | fail | 0.524 (rising) | not evaluated |

Supporting diagnostics:

- Episode-scale ceiling for pure regression: trained on full-session
  descriptors, evaluated with 33-trial descriptors, the reconstruction
  decodes at 0.105 (0.714 with full-session descriptors on both sides).
- Leave-one-source-out distillation: the map trained on five sessions
  reconstructs the HELD-OUT session's table at 0.029 decode.  The
  descriptor-to-table map does not generalise across sessions in pure
  regression form.

Conclusion.  The task "close the source gap" is complete: the distillation
recipe reaches 0.706-0.713 against the 0.6647 gate, matching the
diagnostic ceiling.  But the exercise shows the gate compares
session-specific table quality (AP tables are per-session parameters)
against a session-general read-in, and the only way to pass it is
within-pool memorisation, which destroys cross-session transfer
(LOO 0.03; distill-only target e1_rate 0.333 versus 0.673 for the
co-adapted model whose transfer comes from episodic decode-loss
training).  Proposal for the next review round: recast the E-family gate
in cross-session terms -- dev-target transfer with recorded checks --
rather than within-source fit; the co-adapted model already sits at
0.673 label-free on that measure.
