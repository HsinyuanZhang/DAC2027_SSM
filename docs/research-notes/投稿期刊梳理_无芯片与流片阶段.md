# 投稿期刊梳理：现在无芯片 vs 以后流片

> 整理日期：2026-10-04。按经验整理，影响因子、审稿周期每年都会变，这里只给档次和定位，不列具体数字。投稿前请以期刊官网的 scope 和近期发表的文章为准。
> 结合项目方向：SSM / Transformer 神经解码、跨 session 适配（APST、POSSM）、SSM 在 RRAM 存内计算上的映射。

## 一、先区分三种“无芯片”

能投什么，取决于手上有哪种证据：

| 阶段 | 证据形式 | 典型能支撑的论点 |
|---|---|---|
| A. 纯算法 | 公开数据集上的解码精度、跨 session 泛化、模型参数量和计算量 | 算法更好 / 更适合硬件 |
| B. 算法 + 硬件仿真 | A 加上量化、器件非理想性（RRAM 噪声、漂移）建模，以及 RTL 或架构仿真得到的功耗、面积、延时估计 | 软硬件协同设计可行，能效有优势 |
| C. 器件实测（尚未完整流片） | 在真实 RRAM 阵列上跑核心算子（例如 SSM 状态更新、读出层），外围电路在板上或片外实现 | 存内计算在真实器件上可行 |

C 虽然不是完整芯片，但在器件和材料类期刊里分量很重。王中锐老师组 Nature Computational Science 2025 上的 RRAM 液态状态机（含 BMI 零样本实验）就是这种形式。

## 二、现在（无芯片）可投

### A. 纯算法
| 期刊 | 档次 / 定位 | 适合的稿子 |
|---|---|---|
| **Journal of Neural Engineering (JNE)** | BCI 领域的标准期刊，认可度稳定 | SSM 解码器、跨 session 校准，在 FALCON 或 NLB 等公开基准上验证 |
| **IEEE TNSRE** | 神经康复与 BCI，IEEE 旗舰之一 | 偏应用的解码与适配方法 |
| **IEEE TBME** | 生物医学工程综合类，门槛高于 TNSRE | 方法加上较完整的实验 |
| **TMLR** | ML 期刊，滚动投稿，审稿较快，重正确性而非新颖性 | ICML 被拒后的去处，或者扎实但增量的算法工作 |
| **Nature Machine Intelligence / Nature Communications** | 高档次，需要很强的结果或跨数据集、跨物种的普适性 | 只有当跨 session 结果明显超过 POYO、POSSM、NDT3 时才考虑 |

### B. 算法 + 硬件仿真（软硬件协同）
| 期刊 | 档次 / 定位 | 适合的稿子 |
|---|---|---|
| **IEEE TBioCAS** | 生物医学电路与系统的旗舰，接受仿真或 FPGA 验证的系统工作 | 硬件友好的 BCI 解码器，给出能效和面积估计，**最对口** |
| **IEEE TCAS-I** | 电路与系统主刊 | 存内计算 SSM 架构与映射 |
| **IEEE JETCAS** | 以专刊为主，主题经常是 AI 硬件、存内计算或类脑 | 关注近期专刊征稿 |
| **IEEE TCAD / TVLSI** | EDA 与 VLSI 架构 | 偏架构或映射方法；也可以作为 DAC 论文的扩展版 |
| **IEEE TNNLS** | 神经网络综合，接受硬件感知算法 | 量化、器件噪声鲁棒的 SSM |
| **ACM JETC / TECS** | 新兴计算与嵌入式系统 | 存内计算 SSM 系统级评估 |
| **Neuromorphic Computing and Engineering (IOP)** | 类脑计算专门期刊，较新、圈内认可 | SSM 跑在忆阻器上的仿真研究 |

### C. 有 RRAM 器件实测（适合和王中锐组合作）
| 期刊 | 档次 / 定位 |
|---|---|
| **Nature Electronics** | 顶级，需要系统级演示加上清晰的能效优势 |
| **Nature Computational Science / Nature Communications** | 高档次，王组有先例 |
| **Science Advances** | 高档次综合类 |
| **Advanced Materials / Advanced Science / Advanced Intelligent Systems** | 材料与器件方向的常见出口，Advanced Intelligent Systems 门槛相对低 |
| **npj Unconventional Computing** | 新刊，定位是非常规计算 |
| **National Science Review / InfoMat** | 国内主办的高档次期刊，与国内器件组合作时常用 |

## 三、以后流片后可投

| 期刊 | 档次 / 定位 | 说明 |
|---|---|---|
| **IEEE JSSC** | 电路领域顶刊 | 常见路径是先发 ISSCC 或 VLSI，再受邀投扩展版；也可以直接投 |
| **IEEE TBioCAS** | 生物医学芯片的主力期刊 | BCI 解码芯片最自然的去处；BioCAS 会议论文可受邀扩展 |
| **IEEE SSC-L** | 电路快报，篇幅短 | 常与 VLSI 或 ESSCIRC 会议论文配套 |
| **IEEE OJ-SSCS** | 固态电路学会开放获取期刊 | 审稿较快 |
| **IEEE TCAS-I / TVLSI** | 电路与系统主刊 | 芯片加系统的完整描述 |
| **Nature Electronics** | 顶级 | 存内计算 SSM 芯片完成闭环 BCI 演示时有机会 |
| **Nature Biomedical Engineering** | 顶级 | 需要在动物或临床的真实解码场景里展示芯片 |
| **Nature Communications / Science Advances** | 高档次综合类 | 芯片结果加上神经科学层面的意义 |

## 四、建议路线

1. **现在**：算法结果先发会议（ICML 或 NeurIPS），扩展版或被拒后的版本投 **JNE** 或 **TMLR**。软硬件协同的仿真结果投 **TBioCAS**，或者先投 DAC，再扩展成 **TCAD / TCAS-I**。
2. **有 RRAM 实测之后**：和王组合作，目标是 **Nature Communications / Nature Computational Science**。
3. **流片之后**：先投 **VLSI**（京都，主场），再扩展成 **JSSC**；BCI 应用层面的结果投 **TBioCAS**。如果能完成闭环 BCI 演示，可以冲 **Nature Electronics**。

“会议首发、期刊扩展”在电路和 EDA 领域是惯例：IEEE 期刊一般接受在会议版本基础上有 30% 以上新内容的扩展稿。不过具体比例和规定以各期刊政策为准。
