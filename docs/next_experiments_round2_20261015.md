# 下一轮实验指导（第二轮）：联合的、误差驱动的固定权重前向校准（2026-10-15）

本文件接续 [第一轮指导](next_experiments_labeled_calibration_20261007.md) 和 [第一轮结果](labeled_calibration_results_20261007.md)，优先级高于两者中与之冲突的条目。主路线约束（§0）不变；执行规则与第一轮相同：按 §5 的队列完整执行，遵守 §6 的停止规则。

## 0. 约束（不变，并补充两条决定）

1. 骨架不微调，target 端不写 RRAM。
2. 只用 B 个有标签 trial，B ∈ {1, 2, 4, 8, 16, 33}。
3. target 端的适配只允许：流式累加；固定权重前向（包括冻结 trunk 的前向）；写 SRAM。不允许 target 端的梯度和反向传播。
4. 推理形态：静态读入表加行参数。
5. **决定 1（2026-10-15）：允许多步展开。** F 类方法可以对 B 个有标签 trial 重复执行 S 步“前向 → 累加 → 固定矩阵映射 → 更新表”，S 最多为 10。步数、步长和映射矩阵都要事先在 source 端固定。
6. **决定 2（2026-10-15）：只用 B 个有标签 trial 的数据。** 不使用同一校准时段里的无标签神经数据（trial 间隙、静息段等）。判据 H4 不变。

## 1. 第一轮的结论与遗留问题

### 1.1 结论

1. 固定权重编码器远低于梯度方法 ui_prior，漂移越大差距越大（8 个 trial）：

   | 间隔 | 最好的固定权重变体 | ui_prior |
   |---|---:|---:|
   | 约 1 周 | 0.347 / 0.346 | 0.536 |
   | 约 3.7 个月 | 0.105 | 0.500 |
   | 约 15 个月 | 0.131 | 0.397 |

2. **主要原因：逐 unit 的统计量只来自 B 个 trial，噪声太大，编码器又是逐个 unit 独立映射。** 梯度方法用同样的数据，却让所有 unit 一起最小化解码误差。佐证：
   - 同样的 days 层 target，E1b 用整段 recording 的描述时为 0.673；F1 只用 B 个 trial 的描述，为 0.347；
   - 上一轮的蒸馏诊断：33 个 trial 的描述重建表，解码只有 0.105；整段描述为 0.714。

   按决定 2，不再通过增加无标签数据来解决这个问题。出路在于联合计算。
3. **F7 的残差是联合信号**，所以 F7（0.32–0.35）明显好于手工统计 F3（0.195）。S=3 加共享 G 的配置最好，说明多步展开有用。
4. **每个池只有 6 个 source session，学习型的 G 和编码器在第 200–400 步就过拟合。**
5. **在 M2 上，任何校准都没能超过先验。**

## 2. 本轮的主要思路

把 ui_prior 的梯度更新拆开来看。读入表 T 的梯度为：

∂L/∂T = −Σₜ eₜ xₜᵀ，　eₜ = Σ_ℓ J_{t+ℓ,ℓ}ᵀ r_{t+ℓ}

其中 rₜ 为残差，J_{t+ℓ,ℓ} 是 ℓ 步之前的潜变量对当前输出的雅可比。只有 eₜ（潜变量误差）需要反向传播，其余都是前向和累加。本轮用三种固定权重的方式来近似 eₜ：

| 方法 | eₜ 的近似 | 是否需要元学习 |
|---|---|---|
| **F7-J（主要候选）** | trunk 的**平均雅可比**：eₜ ≈ Σ_ℓ J̄_ℓᵀ r_{t+ℓ}。J̄_ℓ 在 source 数据上离线计算一次，固定为一个时间卷积核 | 不需要：J̄ 由冻结的 trunk 直接算出，不会被 6 个 session 过拟合 |
| F7-Jnet | 一个固定权重网络，以冻结 trunk 前向时的激活为输入，预测 eₜ（思路同 synthetic gradients） | 需要，在 source 上训练 |
| F7-G（第一轮的 F7 扩展） | 学到的反馈矩阵 G，扩展到 S ≤ 10、更长的残差时间窗 | 需要 |

展开 S 步，相当于“用线性化模型做梯度下降”。每一步都只是：一次冻结 trunk 前向（固定权重）、一次时间卷积（固定权重）、一次外积累加、一次表更新。

## 3. 方法细节

### 3.1 F7-J：平均雅可比反馈

**离线准备**（source 端，只做一次，允许使用自动求导）：
1. 在每个 source session 上，用该 session 自己的表，在训练 trial 上计算冻结 trunk 的输出 ŷₜ 对读入潜变量 z_{t−ℓ} 的雅可比，ℓ = 0…L。
2. 对所有时刻和所有 source session 取平均，得到 J̄_ℓ（D×K）。L 取 {8, 16, 32}；学到的时间常数约为 10 个 bin，所以 L=2 太短。
3. 记录平均雅可比的“代表性”：各时刻雅可比与 J̄_ℓ 之间的相对偏差。

**target 端**（全部为固定计算）：
1. 初始化：T⁽⁰⁾ = T₀（先验）。
2. 对 s = 0…S−1：
   1. 用 T⁽ˢ⁾ 做冻结 trunk 前向，得到残差 rₜ（按 source 标签统计量归一化）；
   2. 时间卷积得到潜变量误差：eₜ = Σ_ℓ J̄_ℓᵀ r_{t+ℓ}；
   3. 外积累加：Gᵢ = meanₜ eₜ x_{i,t}（每个 unit 一列，K 维）；
   4. 逐 unit 预条件：除以 qᵢ + ε，其中 qᵢ = meanₜ x_{i,t}²；
   5. 带先验收缩的更新：T ← T + η·G·diag(1/(q+ε)) − ηλ(T − T₀)。
3. 写入 SRAM。

**超参数**：η、λ、S 在 source 端选择。方法是模拟校准：对每个 source session，用留一先验，取 B 个 trial 运行 F7-J，在该 session 的其他 trial 上计算 decode loss。不使用 target 的 query。

**必做测试**：
- 在线性 trunk 上（雅可比为常数），F7-J 一步应与一次梯度下降逐元素相同；
- 在 target 的诊断阶段，离线计算真实梯度（仅用于诊断，不进入校准），报告每一步 F7-J 更新与真实梯度的余弦相似度（梯度对齐度）。

### 3.2 F7-Jnet：由激活预测潜变量误差

- 一个小型固定权重网络（MLP 或单层时间卷积，宽度 64），以冻结 trunk 前向时的层激活和残差窗口为输入，输出 eₜ。
- 训练：在 source 端，用真实的 eₜ（自动求导得到）作为回归目标，同时加上展开 S 步之后的 decode loss。
- 数据不足时容易过拟合：按 source session 分组做留一验证。

### 3.3 F7-G：第一轮 F7 的扩展

- 以第一轮表现最好的配置（S=3，G 共享）为起点，扩展到 S ∈ {3, 5, 10}，残差时间窗 L ∈ {8, 16}。
- 这一组主要用来对照：比较学到的 G 与平均雅可比 J̄，看哪一种更接近真实梯度。

### 3.4 F4：校准时的集合注意力（真正实现）

- 以 F7-J 的一步更新为基础：每个 unit 先得到自己的“误差相关量” Gᵢ 和活动统计；再经过一层固定权重的集合注意力（unit 之间互相参照，K 维，4 个 head），输出修正后的 ΔTᵢ。
- 只在校准时运行，结果折叠成静态表。
- 它回答的问题是：在误差驱动的更新之外，unit 之间的联合推断还能增加多少。

## 4. 数据、对照与门槛

### 4.1 数据

- D1：000688 sub-M 的 days、month、year 三层，K=10 的 AP 骨架（与第一轮相同）。
- D2：M2 的 5 个前向 target，冻结的 wide_n16；先用 source seed 0，入选的方法再用 seed 1、2 复跑。

### 4.2 每张结果表必须包含的对照行

1. 先验（B 对应的输入归一化 + 先验表，不做校准）——**新增，必须有**；
2. ui_prior（梯度上限参照，3 个 seed）；
3. 第一轮最好的固定权重变体（F7，S=3，G 共享）；
4. D2 另加 trunk LoRA，用来量化“放弃微调”的代价。

### 4.3 主要指标

1. query R²（物理单位），以及每个 B 下相对先验的提升。
2. **摊销差距**：ui_prior 减去该方法，按层和按 B 报告。这是本轮的核心指标。
3. 梯度对齐度（F7-J、F7-Jnet、F7-G 的每一步）。
4. H1–H5，H3 改为真正的乘加统计。

### 4.4 判定门槛

| 编号 | 门槛 | 通过后的结论 |
|---|---|---|
| G1′ | B=8 时，F7-J（或 F7-Jnet、F4）在 D1 三层中至少两层，摊销差距 ≤ 0.05 | 固定权重前向校准基本达到梯度方法的水平 |
| G2′ | 在 D2 上，某个方法在 B ≥ 8 时高于 wide_n16 的先验，且高出噪声底以上 | 固定通道数据上，标签校准有实际增益；否则结论为“固定通道上只需先验加行归一化” |
| G3′ | F7-J 第一步与真实梯度的余弦相似度 ≥ 0.5（D1 三层的中位数） | 平均雅可比是合格的反馈近似；否则优先推进 F7-Jnet |
| G4′ | F4 在 F7-J 之上，高出噪声底以上 | unit 之间的联合推断有额外价值 |
| G5 | 每一行满足 H1、H2、H4、H5，并记录真正的 H3 | 不满足的不能列为候选 |

## 6. 停止与继续规则（与第一轮相同）

1. 方法表现差、门槛未通过，都是结果，不是停止的理由。
2. 报错最多花约 1 小时修复；修不好的，记录阻塞原因和证据，跳过该项及依赖它的项，继续执行。
3. 不收敛的，按规则延长到上限；仍不收敛的，标注后继续。
4. 单项耗时超出预期，缩小配置并注明，然后继续。
5. 发现违反 H1、H2 或 H4，修复后重跑受影响的项，不停止整个队列。
6. **不要用占位实现冒充队列项**（第一轮的 F4）。做不了的项，在文档中如实写“未执行”及原因。
7. 只有两种情况可以停止：Q0–Q8 全部完成；或出现影响所有项的硬性阻塞，此时先写阻塞报告。
8. 执行期间不另起新方向，新想法记在结果文档的“后续想法”一节。
