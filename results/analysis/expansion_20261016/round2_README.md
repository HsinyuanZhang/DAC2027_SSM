## 2. 统计口径

* 先对每个 (backbone, target, B, latency, method) 在 seed 上取均值；再按 tier 把同一个 target session 在不同 backbone 下的值取均值；最后对 session 做 10,000 次 percentile bootstrap（seed 0）。“B4-33”先对每个 session 的 B ∈ {4,8,16,33} 取均值。
* 差是配对差。COMBO 在更正后每个 B 都有规则，B4-33 与其他方法覆盖相同的 B。
* **`20140307` 不进任何 tier，也不再单列成结果表。** 可报告计数是 34 / 26。它作为 legacy selection session 留在 (a) 的 pool 里（例如若干 le14 bin）。
* >180 d 的 CI 把 `sc_0309` 的 6 个 session 当成独立样本。它们共用 trunk 和 selection，CI 偏窄。T10 同时给出去掉 `sc_0309`、只留 `sc_0309`、只留 `sm_0512`。
* alpha 的 “n sessions” 是 gap bin 里投票的 session，不是整个 allowed pool。S1 的 n 是 S1 pool；晚 target 上 days trunk 占 10/15–17。
