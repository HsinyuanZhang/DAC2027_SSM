## 1. 协议要点（便于读表）

* 3 个 trunk（Mamba-3 SISO，AP 预训练，budget-extension 规则），每个 backbone 的 trunk source 5 个 session，`pool[-1]` 只用作 validation / selection session：

| backbone | trunk sources | selection session（`pool[-1]`，OOS） | AP steps（best step） | source val trunk R2 | target 数 |
|---|---|---|---|---|---:|
| sc_0629 | 20131220、20150309–0313 | 20150319 | 8000（6300） | 0.618 | 6（month） |
| sc_0708 | 20150629–0706（5 个） | 20150707 | 8000（6300） | 0.741 | 11（5 days + 6 month，2015-11） |
| sc_0713 | 20150703–0709（5 个） | 20150710 | 4000（3000） | 0.828 | 4（days） |

* 方法：P-prior（trunk + prior 读出，不适应）、P0（population calibrator，2 seeds）、P0+R1-stream（source 上选择的 R1 stream 规则）、R2（F7-J，平均 Jacobian J̄ 在该 backbone 的 trunk SOURCE session 上离线计算）、R3（F7-J + readout ridge）。每个 (target, B) 有 8 draws × 2 seeds，B ∈ {1, 4, 8, 16, 33}。
* 聚合单位是 target SESSION：21 个 (backbone, target) 对只覆盖 16 个不同 session（20150713 被三个 backbone 评测，20150709、20150714、20150716 被两个 backbone 评测，等），同一 session 在不同 backbone 下的行不当作独立证据；CI 是 session 层面的 percentile bootstrap（10,000 次，seed 0）与 t 区间。"B4-33" 表示 B ∈ {4, 8, 16, 33} 的汇总（`analyze_expansion.py` 中 B=-1 的含义）。
* stratum：days = target 与 selection session 相隔 ≤ 7 天（以 `gap_days` 为准），month = 约 3.5–4 个月（sc_0629 的 6 个 target 与 sc_0708 的 2015-11 的 6 个 target）。每个 stratum 内 session 数：days 7（9 个 backbone-target 对），month 12（12 个对）。

解读（事实）：

* **P0 相对 P-prior**：days 约 +0.20（B4-33，7/7 session 为正，CI 下界 +0.108），month 约 +0.31（12/12 为正）。month stratum 里 P-prior 的 session 平均绝对 R2 约为 0（−0.008 ~ +0.003），但这是两个 backbone 的平均：sc_0629 为 −0.187，sc_0708 为 +0.185（B4-33），P0 分别拉到 +0.205 与 +0.411。
* **R1-stream（P0+R1-stream）相对 P0**：全部 B 汇总后 days −0.0003（CI [−0.0013, +0.0006]）、month +0.0002（CI [−0.0007, +0.0010]），即没有可测量的增益。B=1 时在 month 上为 −0.0099（0/12 session 为正，CI 不含 0）；B=33 时 month 上 +0.0017（10/12），量级可忽略。R1-stream 的选择在 source 上几乎总是 `full`，lambda 10–100。
* **R2（F7-J）相对 P0**：month 上 B4-33 为 +0.0645（CI [+0.0498, +0.0792]，12/12 为正），随 B 增大单调上升：B=1 +0.0045，B=4 +0.0308，B=8 +0.0611，B=16 +0.0732，B=33 +0.0928。days 上增益很小：B4-33 +0.0063（CI [+0.0026, +0.0103]，7/7 为正），B=33 +0.0093。
* **R3 相对 R2**：几乎相同，B4-33 days +0.0002、month −0.0003（CI 都含 0）；B=33 时 R3 略高（days +0.0014，month +0.0011，month 上 11/12 为正）。readout ridge 在这些数据上没有带来可见的额外增益。
* 因此在 sub-C 上，增益主要来自 P0 本身（相对 P-prior）以及 R2 在长间隔（month）上的 Jacobian 适应；R1-stream 为 null 结果。

## 7. 局限

* 只有 3 个 backbone、16 个不同的 target session，且 days 与 month 各只有 2 个 backbone；backbone 之间的差异（第 3 节）很大，CI 只覆盖 session 抽样，不覆盖 backbone 抽样。

* month 的 R2 增益随 B 单调增长且与 P0 差距 0.09（B=33），但绝对 R2 仍然只有 0.4 左右，远低于 days 的 0.71；这是结果，不是需要修正的问题。
