## 6. P1 的结论在不同 gap 上是否成立

**(a) P0 ≫ prior：方向成立，但幅度比 P1 小，且随 gap 缩小。**
- P0 在 12 个 target 上 B ≥ 2 都高于 P-prior（B=8 平均 +0.106 [0.067, 0.145]）；B=1 有一个 target 反转：0512（P0 − prior = −0.046 [−0.075, −0.015]）。
- 效应随 gap 衰减：~112 d 的两个 target 为 +0.22（B=8），207–272 d 为 +0.15 / +0.05，431–468 d 为 +0.08 到 +0.09；对 days 做线性回归，B=8 斜率 −0.034 / 100 d（p = 0.002，但只有约 5 个不同的 gap 簇，Spearman ρ = −0.46，p = 0.13）。
- “≫”只在 112 d 附近成立（P0 0.565 vs 0.332，0.307 vs 0.105）。在 431–468 d 上 P0 的绝对 R² 只有 0.07–0.26（B=8）、0.07–0.32（B=33），P-prior 0.03–0.16。P1 里 “P0 在 B=8 达到 0.723 / 0.565 / 0.256” 的 days / month 水平**不能外推**到全部 target：12 个 target 平均 P0 只有 0.21。
- 同时 session 本身（N、覆盖率、firing rate）的影响不小于 gap：0626 → 0627（相隔一天）P0 从 0.565 降到 0.307；20141203（N = 10）只有 0.056；0512（5.8 Hz 的低发放率）的 draw 方差最大。

**(b) 可部署层 0–2 与 ui_reg 的差随 gap 增大？——证据弱，不能下这个结论。**
- 差本身很大且为正：ui_reg − (P0+R1s) 在 B=8 为 0.091，B=33 为 0.205，12/12 target 为正。R1-stream 只补回 ui_reg − P0 的一小部分（B=4–33 平均 0.016 / 0.154 ≈ 10%；B=33：0.035 / 0.240 ≈ 15%）。部署层的主要增益来自 P0（prior + 一次性 table），R1-stream 的增益只有 +0.007（B=8）到 +0.035（B=33），B=1 为负。
- 随 gap 的趋势：ui_reg − P0 在 ~112 d 最小（B=8：0.069，B=33：0.157），在 207 d 之后为 0.08–0.13（B=8）/ 0.22–0.32（B=33）；但它不是单调的（431–432 d 的簇比 207 d 低），日期回归斜率不显著（ui_reg − (P0+R1s)，B=8：+0.006 / 100 d，p = 0.40；B=33：+0.014，p = 0.28；B=16 的 Spearman ρ = 0.55，p = 0.067）。因此：**“gap 越大，可部署层与 ui_reg 的差越大”有方向性的迹象（112 d 的差最小），但没有统计显著的单调关系**；12 个 target 只有 5 个不同的 gap 簇，且 session 异质性大。
- 差随 B 增长（0.09 → 0.20）远比随 gap 增长明显。

**(c) 可选的 R3 / R2（F7-J）：在所有 gap 上都有大且一致的增益。**
- R3 − P0：B=8 +0.136 [0.103, 0.168]，B=33 +0.201 [0.158, 0.244]，12/12 target 为正（B ≥ 2），B=1 仅 +0.012。随 gap 增大的趋势（B=33：+0.023 / 100 d，Spearman 0.54，p = 0.07；112 d 簇 0.117 → 461–468 d 簇 0.239）方向一致，但同样不显著。
- 与 P3 的 headline 对照（month 75%、year 77% 的 gap 恢复）：本次 12 个 target 上 pooled B=4–33 的 R3 − P0 = 0.148，ui_reg − P0 = 0.154，即 **R3 ≈ ui_reg 的 96%**；但这个分母依赖 ui_reg 的规则。**ui_reg 规则只在 4 个 source episode / B 上选择（因果集合 {0307}），在 B=8 上选出的规则（λ=1, lr=1e-3, 600 步）明显偏弱：R3 在 B=8 的 12 个 target 上全部高于 ui_reg（ui_reg − R3 = −0.038 [−0.053, −0.022]）**，所以 ui_reg 在这里不是上界；到 B=16、33 才回到 ui_reg 更高（+0.031 / +0.039）。这个参照在不同 B 之间不一致，gap-recovery 比例不宜只看 B=8。
- 112 d 的两个 target 上 R3 − P0 最小（B=8：0.078），与 P3 里 “month 的 gap 小” 一致。

## 7. 局限与没有做的

- 12 个 target 共用同一个 trunk / P0 / 规则，不是独立样本；cross-target CI 不含 trunk、calibrator、规则选择的变异；只有 2 个 P0 seed（seed 间差约 0.01–0.02，与 CI 半宽同量级，见上表最后一列）。
- gap 只覆盖 112–468 d，且集中在 3 处（112–113、431–432、461–468 d），没有 150–400 d 之间的密集覆盖；趋势检验的有效样本数约 5。
- 因果选择集只有 {20140307}（每个 B 4 个 episode），规则噪声大；对 20150xxx 这类晚期 target，这个选择集离 target 更远，而规则没有重新选择（按要求）。更近的 source 选择集（例如 0627、0929、1203 作为更晚 target 的因果集合）**没有使用**。
- 20150511 在这里用的是 month 因果规则，所以它的 R2/R3/ui_reg 与 P3 里的 year 行不同（P0 逐位一致）。
- 没有做：R1（replay 版）、cap256 / contig / ext 变体、定点模拟、per-target 的 oracle/上限、Hyser/DB6 的类似扩展；没有 B=2 以外的新 B；未改动 P1–P3 的任何代码语义；没有用 Colab。
- 图的 x 轴是日历天数，不是 session 数；同一 gap 簇内 target 的差异主要来自 session 质量。
