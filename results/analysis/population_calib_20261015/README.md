## 0. 结论摘要

1. **Q-A（set pooling 是否优于 independent encoder + shrinkage）：在本实验中没有。** P0、P1、P2、P3、P4 在三个 stratum、两个 pool、B∈{1,…,33} 上的 query R² 的配对差（所有 B 汇总）绝对值 ≤ 0.033（逐 B 最大 0.039），且符号随 pool 和 stratum 翻转（例如 P1−P0：days-O +0.014，days-E −0.012，month-E −0.022）；差距与 seed-to-seed 噪声底（days 约 0.01，month/year 约 0.03）同量级。对 B=1/8/33 在 6 个 stratum×pool 单元上取平均，P0 为 0.431/0.509/0.534，P1 0.432/0.502/0.529，P2 0.429/0.498/0.520，P3≈P4 0.435/0.501/0.524。按停止规则，P3/P4 没有在噪声底以上胜过 P1/P2，**不再加深 attention**。P4 与 P3 几乎相同（配对差 <0.001），原因是学到的可靠性 λᵢ 在 unit 之间变化很小（抽查 days-O seed0 target 0616：B=1 时 λ∈[0.74,0.93]，B≥8 时 [0.84,0.95]），log λᵢ 对 softmax 的重加权可以忽略。
2. **相对 P-prior 的提升很大，但来源不是 pooling。** 同一套静态 K×N 表（电极对齐的 source 表均值作 prior，加按 B 个 trial 流式统计得到的 per-unit 残差）把 query R² 从 P-prior 的 days 0.36 / month 0.33 / year 0.13（B=8）提升到 P0 的 0.723 / 0.565 / 0.256（pool O）和 0.683 / 0.547 / 0.282（pool E）。B=1 时 P0-O 已有 days 0.65、month 0.47、year 0.20。
3. **与梯度参照（不可部署）的差距：** days 层所有变体在 B=8 超过 ui_prior（+0.16 到 +0.23）和从电极均值 prior 起步的 ui_elec（+0.07 到 +0.13），B=33 超过 ui_prior（+0.07 到 +0.13）并与 ui_elec 持平（−0.015 到 +0.045）；month 层 B=8 与 ui_prior 持平（−0.04 到 0），比 ui_elec 低 0.06–0.10，B=33 比两者低 0.13–0.20；year 层在 B=8 比 ui_prior 低 0.02–0.05、比 ui_elec 低 0.06–0.09，B=33 低 0.10–0.15。**B=1 时所有 P 变体远高于任何梯度方法**（ui 在 B=1 失败，R² 0.02–0.33）。amortization gap 在 days 层已闭合，在 month/year 层 B≥8 仍存在。
4. **Q-B（瓶颈是统计量噪声还是生成器容量）：二者都不是 B≥8 的主要瓶颈。** P-oracle（描述量来自 target 全部有标签 trial）相对同一生成器的 B=33 预算行为 −0.04 到 +0.006（几乎全为负）；把生成器放宽 4 倍（hidden 256，B=33）在 days 层 +0.005 到 +0.02，month/year 层反而下降 0.02–0.08。噪声主要在小 B 时起作用：P0 的 B=1→B=33 增量 days 0.08–0.09，month 0.09–0.10，year 0.12–0.14，B≥8 后基本饱和。剩下的限制来自冻结 trunk 与手工描述量所含信息，以及只有 5–15 个 source session 的泛化差距（见 §4 的局限）。
5. **Q-C（扩大 source pool）：没有稳定收益。** E−O（配对，所有 B 汇总，P0–P4）：days 层 −0.04 到 −0.065（CI ±0.004，稳定为负），month 层 −0.03 到 +0.02（符号随变体变化），year 层 +0.003 到 +0.026（P0 +0.026，P2 +0.018，其余近 0）。E 池的 best step 中位数 800（O 池 700），没有出现“更多 session 把过拟合推迟”的现象。
6. **标签的作用有限且随层而异（对 DAC 主线的重要提示）：** 训练一个完全不看标签的 P0（`_nolab`，B=8，pool O）：days 0.734 vs 有标签 0.723，即 days 层标签不起作用（P4：−0.011 到 +0.007）；month 0.484 vs 0.565（标签 +0.08；P4 +0.014 到 +0.06）；year 0.229 vs 0.256（+0.03；P4 +0.04 到 +0.057）。评测时把 behavior 循环移位的对照（`_shufY`）给出一致的方向（days −0.015 到 −0.026，month/year −0.04 到 −0.06）。所以 days 层 0.36→0.72 的提升主要来自无标签活动统计与 B 个 trial 的归一化，而不是标签。
7. **约束检查：** 全部 7680 条评测 row（另加 P-prior、ui、oracle、对照）满足 H1（trunk 哈希不变）、H2（目标端 0 次反传，且在每行单独计数）、H4（query 与校准 trial 不相交）、H5（最大 1040 B ≤ 32 KB），unit ratio 检查全部通过。

## 1. 实验设置（与规格的对应与偏离）

**数据与 backbone。** 沿用 `D1_POOLS`：三个 stratum（days：targets 0616/0617；month：0626；year：20150511），每层使用已有的冻结 K=10 AP backbone。month 与 year 两层的 AP checkpoint 相同（同一批 6 个 source、同一 trunk 哈希），所以 month-O 与 year-O 的 calibrator 是同一个训练结果（每个 seed 训练一次，分别在两个 target 上评测）；这一点使 month 与 year 的 O 池结果不完全独立。

**source pool。** O = 原来的 6 个 session。E = 日期严格早于 target 的全部 sub-M CO session，排除 dev（0616/0617）和 final；days 17 个，month 7 个，year 11 个（`session_inventory.json`）。source validation 取日期最晚的 session：O 取 1 个（days 0615；month/year 0306），E 取 2 个（days 0612/0615；month 0306/0307；year 0929/1203）。训练 session 数：O 为 5，E 为 15/5/9。**注意：** E 池中 6 个原始 source 是 trunk 的训练 session，trunk 对它们是“样本内”的；因此 source-val 的绝对值不能直接当作 target 预期（days-O val R² 0.70 与 target 0.72 接近，但 month-O val 0.84 而 target 只有 0.56：验证 session 0306 属于 trunk 的训练集，而 target 0626 在 3.7 个月之后）。validation 只用于选择（m、早停、最终入选），不用于报告 target 数。

**prior（P-prior）。** 每个 target/source session 的 prior 表是“电极对齐的 source 表均值”：把每个 source 的 K×N_s 表按 `unit_to_electrode` 放到 96 电极位置上，按计数归一后在该 session 自己的电极上取列；训练时对原始 source 做 leave-one-out（逻辑与 `run_labeled_calibration.loo_prior` 相同，有单元测试对拍）。P-prior 行 = 该 prior 表 + 用 B 个 trial 的有效 bin 做的输入 z-score，不做任何校准。**发现：** 第一轮 evaluate 路径用的是由 B 个 trial 标签闭式得到的 profile prior（`prior_correct` 在 days target 0616、前 8 个 trial 时 R² 仅 0.135），而训练路径用的是 leave-one-out 电极均值，二者不一致；电极均值 prior 本身在 B 个 trial 归一化下就有 days 0.36、month 0.33。这只是第一轮结果偏弱的可能原因之一，本轮没有单独做消融去隔离。`prior_for_target` 在第一轮脚本里是个返回 None 的桩，没有复用，prior 逻辑在 `population_calib.electrode_mean_table` 和驱动中重写。

**归一化与描述量。** 输入归一化的均值/方差来自 B 个标签 trial 的有效 bin（与评测协议一致，B=1 时噪声真实存在）。每个 unit 的描述量 dᵢ（47 维）全部由可加累加器得到（`PopStats`）：log 发放率与 log 标准差、滞后 1/2/5 自相关、与 prior 潜变量（K=10）的相关、与行为在滞后 −2…+2 的互协方差（D=2）、8 方向分箱平均发放、T4 余弦/正弦系数（3×3 闭式解）、prior 列、log 有效 bin 数、log trial 数。可靠性特征 rᵢ（6 维）：log n、log B、log 发放率、trial 间发放离散度（Fano 型）、行为互协方差的 trial 间一致性 κ（2 维）。流式与批量结果相等（单元测试，误差 1e-9）。

**变体（均为 episodic 训练）。** 实现与规格一致，补充细节：P0 的特征标准化使用 source 拟合的固定常数，不使用第一轮的跨 unit z-score，这样 P0 不含群体信息；P1 的 λᵢ=sigmoid(MLP(rᵢ))，μ₀ 为可学习常数向量；P2 的 μ=mean ψ(d̃ᵢ)（32 维）；P3 的打分 sⱼᵢ=uⱼ·φ(d̃ᵢ)（把 W_kᵀqⱼ 直接参数化为 uⱼ，只依赖 unit i，可 online-softmax，有等价单元测试），固定路由 βᵢⱼ=softmax_j(aⱼ·φ(d̃ᵢ))，μᵢ=Σⱼβᵢⱼzⱼ，生成器输入 [d̃ᵢ, μᵢ, λᵢ]；P4 在打分上加 log λᵢ（rᵢ 取 λᵢ）。生成器为 2 层宽 64 的 MLP，输出层零初始化，因此训练起点等于 P-prior。**未实现行增益/偏移**（规格括号内的可选项）；校准输出只有静态 K×N 表（fp32，N≤26，≤1040 B）。

**训练。** 每个 batch 8 个 episode：随机 source session，B 对 {1,…,33} 做连续 log-uniform（⌊exp U(0, ln 34)⌋），unit dropout 率 U(0,0.3)（至少保留 max(6, N/2) 个），leave-one-out prior；在同一 session 的其余 trial 上取 256 bin 窗口（前 64 bin 为 burn-in，loss 仅在非校准 trial 的有效 bin 上），经冻结 trunk 的 MSE。AdamW lr 1e-3，每 100 步做 source-val（B∈{1,2,4,8,16,33}×2 个抽样，取平均 query R²），patience 8 次且至少 600 步，起始预算 1000 步；best step 落在最后 20% 就翻倍预算（最多 4 次）。2 个 seed。结果：116 个训练 run，全部满足收敛规则（best step 中位 800，范围 100–1600；36 个 run 翻倍过 1 次，0 个触顶）。

H3 说明：由于 N×N Gram 累加（用于与 prior 潜变量的相关）是主要的算术量，固定权重比例偏低（0.14–0.27）。这是累加路径的设计取舍，不是生成器本身；如果把相关特征改成对 K 个潜变量的直接累加（N·K 而非 N²），比例会显著上升，本轮未做。H3 是解析 MAC，不是测量值。

## 3. 解读（Q-A / Q-B / Q-C）

**Q-A。** 答案是否定的：在相同的 B 个 trial 下，reliability-weighted set pooling 生成的静态表并不优于 independent encoder（P0）或 P0 加 shrinkage（P1）。三个原因叠加：（i）每个 session 只有 15–50 个 unit，统计量之间的“群体上下文”本身信息有限；（ii）描述量里已经包含 prior 列和与 prior 潜变量的相关，这已经把 unit 放到 trunk 的潜空间里，群体层面的额外信息（整体增益漂移）没有被生成器用上；（iii）source 只有 5–15 个 session，上下文通路是在极少的 session 层样本上学的，早停在 400–1600 步，容易在 session 层过拟合。P1 的 shrinkage 在 B=1 时的 P1−P0 为 days-O +0.026、days-E −0.021，month −0.018/−0.027（O/E），year +0.017/+0.028，符号不一致，不构成稳定收益。以上（i）–（iii）是候选解释，本轮没有逐项消融。

**Q-B。** 用 oracle descriptor 诊断：给出 target 全部 trial 的统计量不会提升（−0.04 到 +0.004），生成器 4 倍加宽也不会稳定提升。所以 B≥8 时瓶颈不是统计量噪声，也不是 MLP 宽度；B=1–4 时噪声才是主要因素（B=1→33 增加 0.09–0.12）。更可能的瓶颈：这一组手工描述量加上冻结 trunk 能表达的 table 空间，以及 source session 数量。本轮没有做的区分：换更丰富的描述量（例如直接累加 x⊗z 而不是汇总相关）会不会提高上限，需要后续实验。

**Q-C。** 扩大 source pool 没有带来可靠提升：days 层 E 反而显著更差（−0.03 到 −0.065），因为 E 里多出来的 11 个 2014 年 session 与 2015 年 days target 的 unit 群体差距大，而 O 的 5 个 session 是 trunk 自己训练过的、时间上紧邻的 session；year 层 E 有小幅收益（P0 +0.026），E 的验证 session 才是 out-of-trunk，更有代表性。E 池的 best step 与 O 池一样出现在 400–1600 步，没有出现“更多 session 延后过拟合”的现象。因此“第 200–400 步就过拟合”的第一轮现象并不主要由 source session 数量决定；候选原因是 trunk 的 in-sample 偏差与 session 层方差，未单独验证。

**对 DAC 主线的含义（谨慎）。** 可行性的正面证据：静态 K×N 表（≤1 KB）由一次固定权重前向和流式累加得到，在 days 层 B=1–33 全面超过梯度基线，在 month 层 B≤8 持平或超过 ui_prior，同时满足 H1–H5。负面/需要限定的证据：（a）提升的大头来自电极均值 prior 加无标签统计，days 层标签几乎不起作用；（b）pooling 没有额外收益，复杂度没有换来精度；（c）year 层与 month 层 B≥8 仍低于梯度参照 0.1–0.19；（d）所有对比建立在 4 个 target（2 层各 1 个、days 2 个）上，目标数很少。
